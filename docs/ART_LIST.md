# Kaleidoscope — Chapter 1 art list (for Nano Banana Pro)

## How to generate
1. **Attach the anchor** (`art-reference/anchor-haight.jpg`, the Haight & Ashbury microbus image) as a *style reference* on every prompt, and start each prompt with the style line below.
2. **Aspect ratio: 3:2.** Nano Banana Pro has no 16:10, so use 3:2 (the same as the anchor). The game crops to 16:10, which trims about **4% off the top and bottom**, so keep important objects out of the outer 5% top and bottom.
3. **No people, no text, no logos.** Characters are added later as separate portraits, and signs and posters stay blank so the game can letter them.
4. Ask for a **"wide first-person view, eye level"** so every scene shares the same camera.
5. Save your pick as `art-source/ch1/<scene-id>.png` (highest resolution available). The palette-lock script (milestone 3) does the rest.
6. The layout notes say where key objects should sit, so the existing hotspots line up. They're guidance only: the hotspot editor in milestone 3 lets me redraw any hotspot on the final art.

**Style line (start of every prompt):**
> Two-colour screenprint comic illustration in the style of the reference image, printed in **[INK 1]** and **[INK 2]** with off-white paper and deep black shadows. Bold ink linework, flat colour areas, fine screenprint grain, 1960s psychedelic poster art. Wide first-person view at eye level. No people, no text, no letters, no logos, no brand badges.

Layout positions are given as **left→right, top→bottom** fractions of the frame.
